# Strategy Studio 학습 가이드

엑셀과 JSON을 읽어 블랙잭 전략 문구를 관리하는 xlsltojson 프로젝트를 이해하고 직접 실행하는 안내서입니다. 이 가이드는 앱과 분리되어 있어 `docs/html` 폴더만 복사해도 사용할 수 있습니다.

## 먼저 알아보기

- [구조와 데이터 흐름](architecture.md): 브라우저, 공통 변환 로직, CLI와 정적 빌드의 관계
- [입력과 JSON 구조](formats.md): 시트 열, 키, variants와 오류 검사
- [편집 실습](workflow.md): 파일 없이 시작하고 문구를 편집해 내보내기
- [실행과 운영](operations.md): 로컬 실행, 배포와 문제 해결
- [테스트와 감사](audit.md): 확인한 문제, 조치, 남은 제한과 검증 방법

## 한눈에 보는 흐름

1. 엑셀의 시트 또는 기존 JSON을 선택합니다.
2. 변환 결과의 키와 조건을 검토하고 문구를 수정합니다.
3. 검증을 통과한 서비스 JSON과 별도의 검토 파일을 내려받습니다.
4. 업무 서버 반영은 기존 배포 절차에서 수행합니다.

브라우저에서 파일을 읽으므로 앱 자체는 파일을 서버에 전송하지 않습니다. 업무 서버의 접근 제어와 배포는 별도로 구성해야 합니다.

## 빠른 시작

프로젝트 폴더에서 `npm ci`와 `npm run start`를 실행한 뒤 `http://127.0.0.1:4173`을 엽니다. 가이드만 읽는 경우에는 이 명령이 필요하지 않습니다.

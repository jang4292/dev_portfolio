# 편집 실습

## 1. 작업 시작

새 작업에서 빈 전략·오퍼 또는 내장 예시를 선택합니다. 빈 작업에서 Ruleset ID를 비워 두면 `BJ_6D_S17_DAS_NS`가 적용됩니다. 다른 규칙은 직접 입력하거나 `규칙으로 구성`에서 덱 수, 딜러 소프트 17, 스플릿 후 더블과 서렌더를 선택합니다.

기존 JSON 또는 엑셀을 사용할 때는 파일을 선택하고 데이터 유형과 시트를 확인한 뒤 가져옵니다. 엑셀 기본 Ruleset ID는 행에 ID가 없는 경우에 사용합니다.

## 2. 항목과 조건 편집

목록을 검색하거나 유형·변경 상태·검토 상태로 필터링합니다. 항목을 선택해 Answer, Reason과 조건을 편집하고 `변경 적용`을 누릅니다. 항목을 새로 추가하거나 체크박스로 여러 항목을 삭제할 수 있습니다. 삭제 예정 항목은 내보내기 전에 복구할 수 있습니다.

항목의 Ruleset ID를 바꾸면 확인 후 삭제 예정 항목을 포함한 문서 전체의 키와 대표 ID가 바뀝니다. 변경 결과가 충돌하면 어느 항목도 바꾸지 않습니다.

## 3. 비교와 검토

`기준 JSON 선택`은 키와 조건의 추가·누락을 비교합니다. 문구 자체의 차이는 비교하지 않습니다. 각 항목의 검토 상태는 검토 전, 검토 중, 검토 완료 중에서 선택합니다.

## 4. 두 파일 저장

`서비스 JSON 내보내기`는 앱이 사용할 데이터를 만듭니다. `검토 파일 내보내기`는 검토 상태를 별도 JSON으로 저장합니다. 두 파일을 함께 보관하고 다음 작업에서 각각 불러오세요. Ruleset ID가 바뀌면 이전 검토 파일의 키가 맞지 않으므로 새 검토 파일을 저장해야 합니다.

검증 오류가 남아 있으면 서비스 JSON 내보내기가 차단됩니다. 목록의 오류 배지와 항목 상세 내용을 확인해 고친 후 다시 내보냅니다.

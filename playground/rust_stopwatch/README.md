# Rust GUI 스톱워치

Rust를 처음 접하는 사람을 위한 데스크톱 스톱워치 예제입니다.
명령을 터미널에 입력하는 대신 창의 버튼으로 시간을 측정합니다.
Rust 표준 라이브러리로 시간과 상태를 관리하고, `eframe`/`egui`로 창과 화면을 만듭니다.

## 준비와 실행

1. [Rust 공식 설치 안내](https://www.rust-lang.org/tools/install)에 따라 Rust를 설치합니다. `rustup`으로 설치하면 컴파일러 `rustc`와 패키지 도구 `cargo`가 함께 설치됩니다.
2. 새 터미널에서 설치를 확인합니다.

   ```bash
   rustc --version
   cargo --version
   ```

3. 저장소 루트에서 프로젝트 폴더로 이동하고 실행합니다.

   ```bash
   cd playground/rust_stopwatch
   cargo run
   ```

처음 실행할 때 Cargo가 필요한 라이브러리를 다운로드하고 컴파일하므로 인터넷 연결과 시간이 필요합니다.
이 앱은 데스크톱 창을 사용하므로 그래픽 환경이 필요합니다. macOS, Windows, Linux에서 실행할 수 있으며, Linux에서는 그래픽 개발 라이브러리가 추가로 필요할 수 있습니다.
`cargo run` 실행 중 터미널에 컴파일 또는 실행 오류가 나타나면 해당 메시지를 확인하세요.

## 사용법

| 버튼 | 동작 |
|---|---|
| Start / Resume | 측정을 시작하거나 일시정지된 측정을 이어갑니다. |
| Pause | 측정을 일시정지합니다. 정지한 동안의 시간은 누적되지 않습니다. |
| Reset | 측정을 중지하고 시간을 0으로 되돌립니다. |

화면의 `01:02:03.045`는 1시간 2분 3초 45밀리초를 뜻합니다.
시간은 24시간이 지나도 다시 0으로 돌아가지 않습니다.
현재 상태는 메모리에만 있으므로 창을 닫으면 사라집니다.
화면에 사용하는 영문은 egui의 기본 글꼴만으로 표시하기 위한 것입니다.

## 파일 구조

```text
rust_stopwatch/
├── .gitignore        # 컴파일 결과 제외
├── Cargo.lock        # 의존성 버전 고정
├── Cargo.toml        # 프로젝트 정보와 외부 라이브러리
├── README.md         # 실행 및 학습 안내
├── docs/             # 기획·가이드·작업 정리 문서
└── src/
    ├── main.rs       # 창, 버튼, 시간 문자열
    └── stopwatch.rs  # 측정 상태와 단위 테스트
```

`Cargo.lock`은 의존성 버전을 기록하고, 실행 후 `target/`에는 컴파일 결과물이 저장됩니다.
`target/`은 Git에 포함하지 않습니다.

## Rust 기초를 코드와 함께 살펴보기

### 1. Cargo와 프로그램 시작점

`Cargo.toml`은 프로젝트 이름과 사용하는 라이브러리를 정의합니다.
`cargo run`은 필요한 코드를 빌드한 뒤 `src/main.rs`의 `main` 함수를 실행합니다.
`main`의 `eframe::Result<()>`는 창 실행이 성공하면 값이 없는 성공 결과를, 실패하면 오류를 돌려준다는 뜻입니다.

### 2. 구조체와 메서드

`stopwatch.rs`의 `struct Stopwatch`는 관련 데이터를 하나로 묶습니다.
`impl Stopwatch`에는 시작과 일시정지처럼 이 데이터에 적용할 메서드를 작성합니다.
`#[derive(Default)]`는 초기 상태를 만드는 `Default` 구현을 자동으로 제공합니다.
이 예제의 초기 상태는 누적 시간 0, 시작 시각 없음입니다.

### 3. 소유권, 빌림, 변경 가능성

- `let mut stopwatch`의 `mut`는 변수의 값을 변경할 수 있다는 뜻입니다.
- `&self`는 데이터를 읽기 위해 빌립니다. `elapsed_at`은 상태를 바꾸지 않습니다.
- `&mut self`는 데이터를 변경하기 위해 빌립니다. `start_at`, `pause_at`, `reset`이 이를 사용합니다.
- `mod stopwatch;`는 별도 파일의 모듈을 불러오고, `use`는 사용할 이름을 짧게 가져옵니다.

### 4. 시간과 `Option`

`Duration`은 시간의 길이이고 `Instant`는 경과 시간을 측정하기 위한 시점입니다.
스톱워치는 시스템 시계의 현재 시간이 아니라 두 `Instant`의 차이를 사용합니다.
`started_at: Option<Instant>`는 측정 중이면 `Some(시작 시각)`, 정지 중이면 `None`입니다.
`match`로 두 경우를 나누어 현재 경과 시간을 계산합니다.

일시정지할 때는 현재 구간의 길이를 `accumulated`에 더하고 시작 시각을 지웁니다.
다시 시작하면 새로운 시작 시각을 기록하므로 정지해 있던 시간은 포함되지 않습니다.
화면의 시간은 프레임 횟수를 더하는 대신 매번 실제 경과 시간으로 계산합니다.
GUI는 측정 중 약 16ms마다 화면 갱신을 요청하지만, 표시와 실제 갱신 간격은 운영체제의 일정에 따라 달라질 수 있습니다.

### 5. 화면 갱신

`main.rs`의 `eframe::App` 구현에서 `update`는 창을 그릴 때 호출됩니다.
버튼의 `clicked()`가 참이면 해당 스톱워치 메서드를 호출합니다.
측정 중에는 시작 버튼을, 정지 중에는 일시정지 버튼을 비활성화합니다.
시간 문자열은 `format_elapsed`에서 `format!`으로 만듭니다.

## 직접 확인하기

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
cargo fmt --check
cargo test
cargo run
```

테스트는 실제로 시간을 기다리는 대신 기준 시각에 `Duration`을 더해 시작·일시정지·재개·초기화 및 시간 표시를 검증합니다.
창에서는 시작 후 일시정지하고 잠시 기다린 다음 재개해, 정지한 시간이 포함되지 않는지 확인해 보세요.

토스트/알림 센터 UI + 상태별 스타일 시스템

토스트는 “즉시 피드백”, 알림 센터는 “기록/재확인” 용도입니다. 상태 토큰으로 스타일을 통일합니다.

정책 요약

  • Toast: 짧게, 자동 닫힘 기본(중요/위험은 자동 닫힘 비활성 고려)
  • 알림 센터: 읽음/미읽음, 시간, 액션 링크 제공
  • 상태(Info/Success/Warning/Danger)는 토큰으로 일관되게

실무 체크

  • 모바일에서 토스트가 키보드/바텀바와 겹치지 않는지
  • 스크린리더: 토스트는 aria-live 영역에
  • 같은 이벤트 중복 토스트는 디듀프(옵션) 필요

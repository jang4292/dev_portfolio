반응형 카드 그리드(Flex)

모바일 1열 → 태블릿 2열 → 데스크탑 3열. 핵심은 flex-wrap + flex-basis + min-width:0 입니다.

실무 체크포인트

  • 고정폭(px) 남발 금지: 특히 카드/이미지/버튼 폭
  • 긴 텍스트는 overflow-wrap:anywhere로 방어
  • Flex 내부 텍스트 깨짐 방지는 min-width:0
  • 브레이크포인트는 2~3구간이면 충분(320/768/1024 기준)

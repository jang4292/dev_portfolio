그라데이션 배경 + CTA 버튼 템플릿

목적은 단순합니다. 한 줄 가치 제안 + 행동 유도(CTA). 나머지는 잡음입니다.

  • 배경 패턴은 “클래스 1개”로 재사용
  • CTA는 Primary 1개 + Secondary 1개
  • 모바일 우선 → 넓어지면 2열 레이아웃
무료로 시작 데모 보기

* 문구/버튼은 “짧고 명확하게”. 버튼이 3개 넘어가면 설계가 흔들린 겁니다.

FAQ / 도움말 센터 + 아코디언

검색/카테고리 필터 + 아코디언 토글(접근성 포함). 실무 기본형 구조입니다.

빠른 검색

키워드로 질문을 필터링합니다(로컬 검색 샘플).

결과: 0개

자주 묻는 질문

버튼 토글 + ARIA + 키보드(Enter/Space) 지원.

추가 도움이 필요하신가요?

실무에서는 “문의 티켓 생성/챗봇/메일”로 연결합니다.

문의하기(샘플) 운영 정책 보기(샘플)

검증 체크(필수)

  • Tab으로 질문 버튼에 포커스가 가는지
  • Enter/Space로 열고 닫히는지
  • 다중 열기 OFF일 때 한 개만 열리는지
  • 검색/카테고리 변경 시 결과 카운트가 맞는지

NestJS + Fastify

NestJS 11의 모듈·컨트롤러·서비스 구조. Fastify 어댑터와 ValidationPipe의 whitelist/transform, helmet·compression·CORS 설정을 구성했습니다.

  • GET / 인사 응답.
  • GET /lists, GET /user는 문자열 stub. 실제 목록·사용자 저장소 미구현.
  • PORT 또는 3000번 포트.

pnpm build
pnpm typecheck
pnpm test
pnpm test:e2e

데이터 변환

Excel → 블랙잭 JSON

labs/xlsltojson

xlsx 기반 스프레드시트 변환 실험. 폴더명 xlsltojson은 저장소 원본 표기를 유지합니다.

  • xlsx-to-json.mjs: 특정 시트 행을 출력하는 초기 디버그 스크립트. JSON 저장 코드는 주석 상태.
  • xlsx-to-json2.mjs: HARD·SOFT·PAIR 전략, 딜러 카드 정규화, H/S/D/P/R 행동·ruleset·이유·조건부 우선순위 변환.
  • xlsx-to-offers.mjs: insurance/even money, Y/N, 플레이어 상태·업카드·중복 처리.
CLI 예시·한계
node scripts\xlsx-to-offers.mjs .\input\data.xlsx --sheet=offers --rulesetId=BJ_6D_S17_DAS_NS --out=.\out\offers.json

입력 파일과 시트·열 구조를 스크립트 기대 형식에 맞춰야 합니다. 예시 경로는 사용자가 준비할 입력이며 포함된 테스트 데이터가 아닙니다. 실제 변환 결과는 이번 작업에서 실행 검증하지 않았습니다.

WebView의 공통 메시지 형태

// 웹 → 호스트: 호스트가 주입한 호환 브리지 필요
window.webkit.messageHandlers.bridge.postMessage(
  JSON.stringify({ action: "example", payload: { value: 1 } })
);

// Expo 호스트 → 웹: 이벤트의 detail에서 메시지 읽기
window.addEventListener("nativeBridgeMessage", (event) => {
  console.log(event.detail);
});

example은 형식 설명용이며 실제 지원 액션이 아닙니다. 각 앱의 액션 처리기를 확인해야 합니다. Expo의 브리지 이벤트와 Android 인증 앱의 콜백은 자동으로 동일해지지 않습니다.

웹 요청 → 호환 shim → 호스트 메시지 파싱 → 액션 처리 → 웹 응답
Android 인증 앱: 웹 로그인 요청 → Google 로그인 → 서버 토큰 교환 → 앱별 응답

웹 예제만 열어서는 네이티브 브리지·인증이 활성화되지 않습니다. 원본의 한국어·영어 브리지 가이드는 저장소 docs/webview-bridge/에 보존되어 있으며, 독립 배포에 필요한 핵심 내용은 위 설명과 프로젝트 카드에 포함했습니다.

06 / html 폴더만으로 배포

COPY / SERVE / READ
  1. docs/html 폴더의 전체 내용을 복사합니다. assets·demos·history·각 예제 폴더도 함께 필요합니다.
  2. 웹서버의 문서 루트 또는 원하는 하위 디렉터리에 놓습니다. 루트 경로 설정·SPA rewrite·Node 서버는 필요하지 않습니다.
  3. index.html을 엽니다. 문서·검색은 외부 API/CDN 없이 동작합니다. 정적 데모는 HTTP(S)로 접속해야 합니다.
# html 폴더에서 로컬 미리보기
python -m http.server 8080 --bind 127.0.0.1
# http://127.0.0.1:8080/
문서는 파일을 직접 열어도 읽을 수 있습니다. Vite의 ES module, Cocos/WASM 등 실행 데모는 file:// 대신 HTTP(S)가 필요합니다. Python은 관리·미리보기 도구일 뿐 웹서버 배포 시 필수 런타임이 아닙니다.

저장소에서 내용 갱신

python .\docs\html\tools\package_demos.py
python .\docs\html\tools\export_history.py
python -m unittest discover -s .\docs\html\tools -p "test_*.py"
python .\docs\html\tools\check_site.py

도구는 Python 3.10 이상 표준 라이브러리를 사용합니다. 데모 재포장에는 원본 docs와 Git LFS 로컬 객체가, 이력 재생성에는 Git 저장소가 필요합니다. 복사된 사이트를 읽거나 서비스할 때는 원본 저장소가 필요 없습니다.

독립 배포·관리 안내 · 데모 출처·복사 결과 SHA-256

외부 GitHub·학습 자료 링크는 선택적인 온라인 참고 자료입니다. 이 폴더에는 서버 코드·인증 설정·토큰·비공개 백업·앱 릴리스 파일을 포함하지 않습니다. 정적 공개 데모의 기존 클라이언트 코드는 포함됩니다.

헤더 고정 + 2단 레이아웃

상단 헤더는 sticky, 레이아웃은 grid(좌 260px + 우 가변)로 구성합니다.

이 템플릿의 목적은 “관리자 화면/대시보드/문서 페이지”에서 가장 흔한 구조를 안정적으로 만드는 것입니다. 핵심은 grid 기반 2단 + sticky 헤더/사이드 + min-width:0로 텍스트 깨짐을 방어하는 것입니다.

카드 리스트(본문 예시)

Item 1

긴 텍스트/URL이 들어오면 레이아웃을 밀 수 있습니다. overflow-wrap과 min-width:0로 방어합니다.

Item 2

sticky 요소는 부모에 overflow가 걸려 있으면 정상 동작이 깨질 수 있습니다.

Item 3

2단 레이아웃은 flex로도 가능하지만, “고정 + 가변”은 grid가 가장 단순합니다.

실무 팁

  • 헤더 sticky는 top:0 + z-index가 세트입니다.
  • 사이드 sticky는 헤더 높이를 고려해 top: calc(...)로 맞춥니다.
  • 2단 grid에서 본문 컨테이너에 min-width:0를 꼭 둡니다.

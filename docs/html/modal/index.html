모달/다이얼로그 UI

HTML 표준 <dialog> 기반. CSS로 UI 완성도를 올리고, JS는 동작만 최소화합니다.

사용 가이드

  • 모달은 “필요할 때만”. 남발하면 UX 악화.
  • 닫기 경로는 최소 2개 이상 제공(ESC/버튼).
  • 폼 모달은 submit/cancel을 명확히 분리.

기본 모달

기본 안내/확인용 모달. 컨텐츠가 길어지면 body 스크롤이 생깁니다.

실무에서는 “모달 안에서 또 모달”은 피하는 게 안전합니다(포커스/레이어링 지옥).

프로필 수정

필수 입력. 2자 이상.

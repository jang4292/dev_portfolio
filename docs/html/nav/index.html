접근성 내비게이션 + Skip Link + 현재 위치 표시

Tab → Skip Link 노출 → Enter로 main 포커스 이동. 스크롤/클릭 시 현재 섹션 표시.

소개

Skip Link는 키보드/스크린리더 사용자의 “바로가기”입니다. 헤더가 sticky일수록 중요합니다.

이 섹션들은 데모용 콘텐츠입니다. 스크롤을 내려 nav의 active 상태를 확인하세요.

기능

  • Skip Link (focus 시 표시)
  • 키보드 포커스( :focus-visible )
  • 현재 위치 표시(IntersectionObserver)
  • 헤더 sticky 고려(스크롤 보정)

실무에서는 “페이지 내 이동”과 “라우팅(페이지 이동)”을 구분해서 aria-current 값을 설계합니다.

가격

내비 링크 클릭 시 기본 앵커 스크롤 대신 smooth scroll로 이동하며, sticky header 높이만큼 오프셋을 보정합니다.

FAQ

FAQ는 아코디언/토글 UI와 연결하면 접근성 이슈가 자주 생깁니다(버튼/aria-expanded/aria-controls).

Skip Link는 꼭 필요한가요?

헤더/내비가 길면 스크린리더/키보드 사용자에게 필수에 가깝습니다.

현재 위치 표시는 어떻게 구현하나요?

IntersectionObserver로 섹션이 뷰포트에 들어오면 nav를 업데이트합니다.

검증 체크(필수)

  • Tab 첫 입력에서 Skip Link가 보이는지
  • Skip Link Enter 시 main으로 포커스가 이동하는지(tabindex=-1)
  • 섹션 이동 시 nav active 및 aria-current가 변경되는지
  • 모바일(320)에서 nav 줄바꿈/깨짐 없는지
